## Prediction of Time Series Data using R

This forecasting report was completed during my study in Macquarie University. It includes three cases, which are the “Median Price of Established House Transfers in Sydney”, “COVID-19 cases admitted to Australian hospitals”, and “Industrial Production Index”. This report aims to forecast the next four quarters for house prices, the next four weeks for ‘COVID-19’ hospitalizations, and the next twelve months for industrial production.
